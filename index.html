Kết nối Google Sheets
Làm theo 3 bước dưới đây, chỉ cần làm 1 lần duy nhất.
Sau đó quản lý có thể xem dashboard online mọi lúc.
1
Tạo Google Apps Script làm cầu nối

Mở Google Sheets của bạn → nhấn Extensions (Tiện ích mở rộng) → Apps Script → xóa code cũ → dán đoạn code bên dưới vào → nhấn Save (💾)

// Dán vào Apps Script của Google Sheets // Extensions > Apps Script > xóa code cũ > dán vào > Save const SHEET_ID = '1IdTXke1HYTPyKDvF-Jv8ejQqRja4LnlHu-rp_z7jSXg'; function doGet(e) { const sheetName = e.parameter.sheet || 'Tương tác'; try { const ss = SpreadsheetApp.openById(SHEET_ID); const ws = ss.getSheetByName(sheetName); if (!ws) return out({ error: 'Sheet không tồn tại: ' + sheetName }); const data = ws.getDataRange().getValues(); if (data.length < 2) return out({ headers: [], rows: [] }); const headers = data[0].map(h => h.toString().trim()); const rows = data.slice(1).map(row => { const obj = {}; headers.forEach((h, i) => { let v = row[i]; if (v instanceof Date) v = Utilities.formatDate(v, 'Asia/Ho_Chi_Minh', 'dd/MM/yyyy HH:mm'); obj[h] = (v !== null && v !== undefined) ? v.toString().trim() : ''; }); return obj; }).filter(r => Object.values(r).some(v => v !== '')); return out({ headers, rows, count: rows.length }); } catch(err) { return out({ error: err.message }); } } function out(data) { return ContentService .createTextOutput(JSON.stringify(data)) .setMimeType(ContentService.MimeType.JSON); }
✓ Đã copy!
2
Deploy Apps Script thành Web App

Trong Apps Script → nhấn nút Deploy → New deployment → chọn type "Web app" → điền:

• Execute as: Me (your Google account)
• Who has access: Anyone (quan trọng — phải chọn Anyone)

→ Nhấn Deploy → copy Web app URL được tạo ra.

⚠ Lần đầu sẽ có popup "Review permissions" → nhấn Advanced → Go to (unsafe) → Allow. Đây là script của chính bạn, hoàn toàn an toàn.
